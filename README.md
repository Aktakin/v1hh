# version1hh

Standalone HackHilis Version 1 (hv1 game UI) — single folder, easy Vercel deploy.

## Local

```bash
npm install
npm start
```

Open the URL Vite prints (usually http://localhost:5173).

## Deploy on Vercel

1. Import this GitHub repo
2. Framework: Vite (auto)
3. Root Directory: leave as `.` (repo root)
4. Deploy

No monorepo / shared `client/` folder required.
